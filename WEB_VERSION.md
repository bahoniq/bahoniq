# BahonIQ Web Version

Запуск из корня проекта:

1. Установить зависимости: `py -m pip install -r requirements_web.txt`
2. Запустить `run_web.bat`
3. Открыть `http://127.0.0.1:8000`

## Подключённые модули

- ANALYTICS AI — просмотр Excel и создание PDF/PowerPoint.
- Excel AI — план, подтверждение и выполнение операций.
- PDF Center — конвертация, объединение, разделение и оптимизация.
- Ticket Writer AI — профессиональное оформление обращений через Облачный ИИ с безопасным резервным режимом.
- Заметки — сохранение на сервере и автосохранение в браузере.
- Телефонный справочник — поиск, добавление, изменение и удаление контактов.
- Code Academy — Python, SQL, книга, исходный код и конструктор. Все разделы открыты сразу.

AnyDesk, очистка компьютера, поиск файлов-дубликатов, системные ярлыки и установщики не подключаются к веб-интерфейсу.

Пользовательские файлы обработки хранятся во временных каталогах и автоматически удаляются через час. Заметки и справочник находятся в `web_app/data`.
