# BahonIQ Work Center в локальной сети

На компьютере-сервере откройте PowerShell в папке Work Center:

```powershell
py -m pip install -r requirements_web.txt
```

Убедитесь, что Ollama запущена, затем запустите `run_web.bat`.

При запросе брандмауэра Windows разрешите Python доступ только для частной
сети. Узнайте IPv4-адрес командой `ipconfig`. Другие компьютеры открывают:

```text
http://ВАШ-IP:8000
```

Например: `http://192.168.1.50:8000`.

Это пилот для доверенной локальной сети. Не открывайте порт 8000 напрямую в
интернет. Загруженные файлы хранятся во временной папке сервера и автоматически
удаляются через один час.

## Модули

- `ANALYTICS AI` — загрузка Excel, выбор листа, предпросмотр, формирование PDF и PowerPoint через локальную Ollama.
- `EXCEL AI` — подготовка плана операций, подтверждение и скачивание изменённого Excel.
- `PDF CENTER` — конвертация, объединение, разделение и оптимизация документов.

Для `Word → PDF` требуется установленный Microsoft Word. Остальные операции
PDF Center выполняются локальными Python-компонентами.
