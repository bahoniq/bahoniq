# BahonIQ Code Academy Pro — итоговая учебная система

## Обязательный маршрут

1. Python Studio — 48 последовательных уроков.
2. SQL Laboratory — 35 последовательных уроков.
3. Книга готового приложения — 19 глав с переходом к точному коду.
4. App Builder — самостоятельная работа со всеми слоями проекта.
5. Практическая аттестация — новый вариант при каждой попытке.

Следующий раздел открывается только после завершения предыдущего. ИИ-наставник
доступен на всём маршруте.

## Профессиональное ядро

- Python-задания могут проверяться настоящим интерпретатором в отдельном процессе.
- Каждая проверка запускается в новой временной папке с ограничением времени и вывода.
- Поддерживаются открытые и скрытые тестовые случаи, стандартный ввод и точное сравнение вывода.
- SQL возвращает типизированные столбцы и строки, а не только форматированный текст.
- SQL-задания могут сравниваться с точным эталонным результатом, включая порядок строк.
- Для SELECT доступен `EXPLAIN QUERY PLAN`.
- Запросы выполняются на новой копии учебной базы; записи в режиме проверки запрещены.
- Интерфейс Python Studio и SQL Laboratory подключён к новому механизму проверки.
- Старые тесты исправлены так, чтобы архив был самодостаточным и импортировал `code_academy`.

## Содержание Python

Отдельно изучаются `int`, `float`, `bool`, `None`, `str`, `bytes`, `list`,
`tuple`, `set`, `frozenset`, `dict`, `range`, преобразования типов, условия,
циклы, функции, область видимости, генераторы, исключения, файлы, JSON/CSV,
модули, ООП, типизация, стандартная библиотека, SQLite, Tkinter, API,
конфигурация, логирование, тестирование, отладка и слоистая архитектура.

## Учебный проект конструктора

```text
main.py
app/application.py
api/task_api.py
models/task.py
services/task_service.py
data/task_repository.py
ui/main_window.py
settings.py
tests/test_service.py
```

UI вызывает API, API — Service, Service — Repository, Repository — SQLite.
Модель и настройки не зависят от интерфейса. Экспортированный шаблон имеет
собственные работающие `unittest`-тесты.

## Аттестация без заучиваемой базы

Фиксированный банк теоретических вопросов удалён. Python-задача получает новые
коэффициенты и скрытые данные, SQL-задача — новый порог и новый эталонный
результат. Проверяется выполнение программы или точный результат запроса.

## Проверка

Из родительской папки пакета:

```bash
python -m unittest discover -s code_academy/tests -v
```

Дополнительные зависимости для тестов не требуются.

Пакет проходит 53 автоматические проверки. Экспортируемый проект дополнительно
проходит три собственных теста бизнес-логики.
