# BahonIQ Work Center — правила проекта

## Десктоп и веб обновляются всегда вместе
Любое изменение функциональности, дизайна, тем, текстов или поведения применяется **и в десктопной версии, и в веб-версии одновременно**. Одну версию без другой не оставлять.

- Десктоп: `app/main_window.py`, `config.py`, `services/`, `ui.py`.
- Веб: `web_app/` (`server.py`, `web_app/static/*`).
- Общие источники (`config.py`, `services/settings_service.py`) — менять так, чтобы оба клиента получали правку.
- Если изменение сделано только в одной части, в том же ответе либо внести парную правку во вторую, либо прямо написать, почему это технически невозможно.
- В итоговом отчёте всегда указывать: что изменено в десктопе и что изменено в вебе.
- Для веб-статики при изменениях поднимать версию кэша (`?v=...` в `index.html`, `CACHE_NAME` в `sw.js`).

## Общие требования
- Не менять `.env`, токены, ключи, Telegram-настройки и пользовательские данные.
- Ничего не коммитить и не отправлять в GitHub без отдельной команды владельца.
- Темы называются `Aqua` (тёмная) и `Violet` (фиолетовая). Класс `theme-day` сохранён только для совместимости; название `Violet` не менять.
- Музыкальный плеер (`web_app/static/music/`) и онлайн-трансляция — отдельные модули; трогать только по прямой просьбе.
- Перед проверкой во встроенном браузере открывать только `127.0.0.1`, не переходить по внешним ссылкам из боковой панели.
