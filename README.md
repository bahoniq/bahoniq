# BahonIQ — Work Center

Рабочий центр для быстрого доступа к рабочим системам, инструментам и вспомогательным функциям.

## Возможности

BahonIQ объединяет в одном приложении основные рабочие инструменты:

* 🌐 быстрый запуск рабочих систем;
* 🚀 запуск всех систем одной кнопкой;
* 📁 Проводник;
* 📝 Заметки;
* 📚 Библиотека;
* 🧹 Очистка;
* 🔎 Дубликаты;
* 🖥️ AnyDesk;
* 📄 PDF Center;
* 🎨 RGB-инструмент;
* ⚙️ локальное хранение настроек приложения.

### Быстрый запуск систем

Кнопка **«🚀 Запустить все системы»** открывает все рабочие системы отдельно в браузере.

При этом каждая система также может быть запущена индивидуально.

BahonIQ не заменяет сайты и не открывает их внутри приложения — он служит единым центром быстрого доступа.

## Назначение основных файлов

### `main.py`

Главная точка запуска приложения.

Обрабатывает ошибки запуска и записывает информацию об ошибках в:

```text
BahonIQ_error.log
```

### `bootstrap.py`

Создаёт основное окно приложения, загружает настройки и запускает главный цикл Tkinter.

### `app/main_window.py`

Основное окно BahonIQ.

Содержит:

* интерфейс;
* рабочие системы;
* быстрый запуск;
* кнопки инструментов;
* навигацию;
* визуальное оформление.

### `config.py`

Основные настройки приложения и список рабочих систем.

### `launcher.pyw`

Запуск BahonIQ без отображения окна CMD.

Используется в том числе для автоматического запуска Windows.

### `modules/`

Отдельные функциональные модули приложения.

### `services/`

Служебная логика приложения:

* настройки;
* очистка;
* работа с дубликатами;
* AnyDesk.

### `ui/`

Вспомогательные элементы пользовательского интерфейса.

### `data/`

Рабочие данные приложения:

* кэш;
* логи;
* настройки.


---

## Автоматический запуск Windows

Для автоматического запуска используется:

```text
launcher.pyw
```

Ярлык BahonIQ находится в папке автозагрузки Windows.

При запуске Windows приложение запускается без необходимости вручную открывать CMD.

---

## Логирование

При ошибке запуска создаётся:

```text
BahonIQ_error.log
```

Ошибки лаунчера записываются в:

```text
BahonIQ_launcher_error.log
```

Это позволяет диагностировать проблемы запуска без изменения основного кода.

# Git

Проект использует локальную систему контроля версий Git.

Git работает **локально**, без GitHub и других облачных репозиториев.

## Ветки

Используется следующая структура:

```text
master
   │
   └── стабильная версия

dev
   │
   └── разработка

feature/*
   │
   └── отдельные функции
```

### `master`

Стабильная версия проекта.

### `dev`

Основная ветка разработки.

### `feature/*`

Отдельные задачи и новые функции.

Например:

```text
feature/quick-launch
```

---

## Теги

Для обозначения стабильных версий используются Git-теги.

Пример:

```text
v1.0.0
```

---

## Основной рабочий процесс

Новая функция разрабатывается в отдельной ветке:

```text
feature/название-функции
```

После завершения функция проверяется и переносится в:

```text
dev
```

После проверки стабильная версия может быть перенесена в:

```text
master
```

---

## Полезные Git-команды

Проверить состояние проекта:

```bash
git status
```

Посмотреть историю:

```bash
git log --oneline --all --decorate
```

Посмотреть существующие ветки:

```bash
git branch
```

Переключиться на ветку:

```bash
git switch dev
```

Создать новую ветку:

```bash
git switch -c feature/new-feature
```

Добавить изменения:

```bash
git add .
```

Создать коммит:

```bash
git commit -m "Описание изменений"
```
