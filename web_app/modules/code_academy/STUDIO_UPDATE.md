# BahonIQ Code Academy — Studio Edition

Обновление от 05.11.2026.

## Установка

1. Закрой BahonIQ и сохрани резервную копию установленной папки `modules/code_academy`.
2. Скопируй `code_academy` из архива в `modules` с заменой файлов. Вложенную папку `code_academy/code_academy` создавать не нужно.
3. Перезапусти приложение. В заголовке появится **Studio Edition**.

Новые сторонние библиотеки не нужны. Сохраняются Python → SQL → книга и код → конструктор, история наставника и прежний прогресс.

## Редактор

Общий `CodeEditor` подключён к действующим Python Studio, SQL Laboratory, конструктору, практической аттестации, исходникам книги и исследователю файлов.

- Подсветка ключевых слов, строк, чисел, комментариев; для Python — встроенных имён.
- Python, SQL, JSON; язык в конструкторе и книге переключается по расширению файла.
- Номера строк и подсветка парных скобок у курсора.
- Автоотступ Python после двоеточия; Tab вставляет четыре пробела.
- Ctrl+Space предлагает ключевые слова, встроенные имена и имена из текущего текста. Это простое дополнение слов, не анализ типов как в большой IDE.
- Контекстное меню, копирование, вставка, выделение, отмена и повтор. В текстах уроков и справочника также подключены команды копирования.
- Незавершённый код не блокирует редактирование. Для буферов более 200 000 символов подсветка отключается ради отзывчивости.

## Выполнение

Действующая студия и проверка практики используют один настоящий Python через `python_runtime.py`. Старый ограниченный `SafePython` остаётся для совместимости со старыми модулями, но больше не вызывается кнопкой Python Studio.

В Python Studio нажми «Запустить». `print()` и ошибки появляются в консоли. Для `input()` введи строку в поле под консолью и нажми Enter или «Ввести». «Конец ввода» отправляет EOF, «Стоп» останавливает процесс. Лимит интерактивного запуска — 60 секунд и 50 000 символов вывода; проверки упражнений ограничены тремя секундами на запуск.

Запуск идёт в отдельном процессе и временной рабочей папке. Файлы, созданные относительными путями, не сохраняются между запусками. Это защита от случайного изменения рабочей папки, **не полноценная системная песочница**: запускай собственный доверенный учебный код. Ограничения на некоторые системные импорты сохранены.

Многофайловые приложения и настоящие окна Tkinter по-прежнему относятся к конструктору и экспортированному проекту. Этот выпуск не реализует отдельный многофайловый отладчик или полноценную IDE.

## Практика

`exercises.py` содержит конкретные условия и проверки для всех активных идентификаторов: 48 Python и 35 SQL. Условия синхронизированы с действующим курсом, а не со старыми `p01/s01`.

Примеры в теории остаются примерами. В практике указаны необходимые имена функций, переменных, входные данные, столбцы и ожидаемое поведение. Проверка Python вызывает функции на предусмотренных входах и проверяет граничные случаи; часть уроков дополнительно требует изучаемую конструкцию. Это конечные учебные проверки, а не доказательство правильности любой программы и не защита от намеренного обхода.

Для запросов SQL сравниваются столбцы, строки и порядок на двух свежих наборах данных. Для DDL/DML проверяются структура таблиц, отдельные ограничения и изменения данных в одноразовой базе. Учебные условия некоторых старших уроков сделаны конкретнее: например, создание GUI проверяется через подставные виджеты без открытия окна, а настоящее окно собирается в конструкторе.

Простой `print("ничего не решено")` не засчитывает ни один Python-урок, `SELECT 1` — ни один SQL-урок. Корректные альтернативные решения допустимы; полное совпадение текста с эталоном не требуется.

Старые отметки прохождения не удаляются. Дополнительный счётчик «Практика» показывает только задания, подтверждённые новой проверкой. Закрытые ранее разделы остаются доступными по прежнему прогрессу.

## Черновики и наставник

При переходе к другому уроку текущий черновик сохраняется. При обычном закрытии окна академии черновики сохраняются, запущенные программы останавливаются. При принудительном завершении всего процесса последние несохранённые изменения могут потеряться — для ручного сохранения остаётся Ctrl+S.

Кнопка наставника передаёт язык, название урока, условие практики, код и последнюю ошибку. По умолчанию используется режим подсказки без готового решения. Настройка локальной модели сохранена.

Неиспользуемые старые экраны учебника и экзаменов удалены из `ui.py`; совместимые модули старых движков сохранены. Генерируемая практическая аттестация остаётся, новый большой банк вопросов не добавлялся.

## Проверка сборки

79 автоматических тестов прошли. Среди них проверки:

- запуска всех 48 примеров Python новым движком;
- корректных решений всех 48 Python- и 35 SQL-практик;
- отклонения пустых по смыслу решений для каждого урока;
- границ оценок, ошибочной функции, альтернативного верного решения;
- SQL-условий, ограничений, одноразового состояния базы;
- интерактивного ввода после приглашения, Unicode, traceback, тайм-аута, остановки и ограничения вывода;
- токенизации Python/SQL/JSON и незавершённого кода;
- прежних функций книги, конструктора, маршрута и наставника.

Запуск из корня приложения:

```bash
python -m unittest discover -s modules/code_academy/tests -v
```

Если пакет `code_academy` не доступен как верхнеуровневый импорт, запускай с `PYTHONPATH=modules` (PowerShell: `$env:PYTHONPATH="modules"`).

**Не проверено здесь:** визуальное отображение Tkinter на Windows, масштабирование экрана и живая локальная Ollama. В среде сборки нет графического дисплея. Визуальный пошаговый отладчик с состоянием переменных остаётся следующим этапом, не заявляется готовым в этом выпуске.
